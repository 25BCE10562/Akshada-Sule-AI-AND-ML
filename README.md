Stock Price Prediction using Machine Learning
1. Introduction
Stock market prediction is a challenging problem in Machine Learning. This project predicts the next
day's stock price using historical data and a Linear Regression model. Data is collected from Yahoo
Finance.
2. Objective
1 Build a simple stock prediction model
2 Understand time-series data
3 Apply Linear Regression
4 Visualize predictions
3. Tools and Technologies
1 Python
2 Pandas, NumPy
3 Matplotlib
4 Scikit-learn
5 yFinance API
4. Methodology
Data is collected, preprocessed, and used to train a Linear Regression model. The model predicts
next-day prices and results are visualized.
5. Results and Analysis
The model shows a linear trend between actual and predicted prices. It works well for basic
understanding but has limited accuracy.
6. Limitations
1 Uses only closing price
2 Ignores external factors
3 Not suitable for real trading
7. Future Enhancements
1 Use LSTM models
2 Add more features
3 Build web app
8. Conclusion
This project demonstrates how Machine Learning can be applied to financial data for prediction
